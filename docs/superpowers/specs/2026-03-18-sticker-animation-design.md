# Sticker Animation Design Spec (ProductLineup)

## 概要
`components/ProductLineup.tsx` において、音響連動型スマホライトの製品紹介エリアに独自のイメージ表示（シール画像切り替えアニメーション）を実装する。

## 採用されたデザイン
**A案 (シンプルなフェード切り替え)**
- 同じスマートフォン型のプレースホルダー内で、2枚のシール画像（ステッカー）が一定間隔でフェードしながら切り替わる。
- 使用する画像:
  - `public/images/スマホペンライトデコシールPKイメージ_野球チームバラエティ.png`
  - `public/images/スマホペンライトデコシールPKイメージ_野球チームマスコット.png`

## 実装方針
1. **対象コンポーネント**: `components/ProductLineup.tsx`
2. **対象箇所**:
   - `PRODUCTS[0]` (id: "torch-sticker") の画像表示エリア。
   - 現在のプレースホルダー（`Smartphone` アイコンと "Image Area" テキスト）を画像に置き換える。
3. **アニメーションの実装**:
   - Tailwindの標準機能では独自周期のフェードアニメーション（キーフレーム）が難しいため、インラインスタイルまたは `global.css` に定義を追加して、`Next/Image` または `img` タグで2枚の画像をそれぞれ絶対配置しつつ交互に不透明度(`opacity`)をクロスフェードさせる。
   - 例: 6秒周期で画像1と画像2の不透明度を切り替える（遅延させる）。

## 検証方法
- `pnpm run dev` でローカルサーバーを起動。
- `/` の「音響連動型スマホライト＆立体シール」セクションをブラウザで目視確認。
- アニメーションが指定した2枚の画像で正しくクロスフェードしているか確認。
- モバイルビュー（レスポンシブ）でもレイアウト崩れがないか確認。
